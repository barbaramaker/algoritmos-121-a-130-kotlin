# Algoritmos 121 a 130 em Kotlin

Este repositório contém os algoritmos de 121 a 130, originalmente escritos em Portugol e convertidos para Kotlin.

O objetivo da atividade é praticar a linguagem Kotlin e aprofundar o uso de estruturas condicionais aninhadas, operadores relacionais e lógicos, validação de intervalos, manipulação de strings e caracteres, além de aplicações práticas de lógica de negócios, geometria e estatística básica.

**Algoritmos desenvolvidos**

- Algoritmo 121: Efetua a leitura de cinco números inteiros diferentes e identifica o maior e o menor valor.
- Algoritmo 122: Verifica se três números podem ou não formar os lados de um triângulo.
- Algoritmo 123: Classifica um triângulo segundo os comprimentos dos lados (Equilátero, Isósceles ou Escaleno).
- Algoritmo 124: Classifica um triângulo segundo os ângulos (Retângulo, Obtusângulo ou Acutângulo).
- Algoritmo 125: Informa a faixa etária de uma pessoa (maior de idade, menor de idade ou maior de 65 anos).
- Algoritmo 126: Verifica se um número é igual a valores específicos ou se está dentro de um intervalo determinado (500 a 1000).
- Algoritmo 127: Calcula a média escolar de um aluno com base em duas notas e exibe o status de aprovação, reprovação ou prova final.
- Algoritmo 128: Valida se um verbo está no infinitivo e identifica a sua respectiva conjugação (1ª, 2ª ou 3ª).
- Algoritmo 129: Calcula o desconto do INSS com base em faixas salariais progressivas.
- Algoritmo 130: Calcula o valor de venda de um produto aplicando margens de lucro condicionais (45% ou 30%).

**Comentários sobre os exercícios**

Neste bloco, consegui consolidar o uso de estruturas condicionais avançadas aplicadas a problemas variados do mundo real, como geometria (regras de existência e classificação de triângulos), manipulação de strings e caracteres (análise de terminações de verbos no infinitivo e suas vogais temáticas) e cálculos financeiros e fiscais (tabelas de INSS e margens comerciais).

Também explorei recursos idiomáticos do Kotlin, como checagem de coleções para unicidade, operadores de intervalo (`in`), tratamento de strings e funções de formatação numérica, garantindo um código limpo, seguro e legível.

**Ferramentas utilizadas**

- IntelliJ IDEA

**Organização**

Os arquivos estão organizados individualmente, de Algoritmo121.kt até Algoritmo130.kt, dentro da pasta src/main/kotlin.

Cada arquivo contém o enunciado, o código original em Portugol e sua conversão para Kotlin.
